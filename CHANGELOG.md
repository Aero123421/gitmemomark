# Changelog

## 0.2.0 — Quiet Editorial

- Adopt the approved paper-and-ink design in the save popup, with matching light and dark options screens.
- Put the article title and memo first; group folder selection and tags in a separate filing area.
- Make the title editable across multiple lines and keep the compact save action visible in the footer.
- Retain light/dark/system theme selection, Markdown preview, classification, and existing storage/privacy behavior.

This remains a developer preview, not a Chrome Web Store release. Authenticated X interaction and real GitHub/Jev write flows remain outside the tested end-to-end coverage; see the README for limitations.

## 0.1.0

Initial Apache-2.0 public developer preview: GitHub Markdown saves, folder classification, X integration, web article extraction, and light/dark/system themes.
