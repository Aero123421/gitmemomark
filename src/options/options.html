GitMemoMark の設定

X のポストや Web ページを、あなたの GitHub リポジトリにフォルダ分けして保存します。

保存先保存と表示フォルダ・自動仕分けサイト連携

01 · 保存先の GitHub リポジトリ

トークンの作り方
  1. GitHub → Fine-grained personal access token の作成画面を開く
  2. 「Repository access」→「Only select repositories」で保存先のリポジトリだけを選ぶ
  3. 「Permissions」→「Contents」を Read and write にする
  4. 作成したトークンをここに貼り付ける

トークンはこのブラウザの中（chrome.storage.local）にだけ保存され、同期されません。

02 · 保存と表示

保存ボタンを押したとき
すぐ保存するときの保存先（ショートカット Alt+Shift+S や右クリックの「すぐ保存」にも使われます）

03 · フォルダ

リポジトリに既にあるフォルダは自動で候補になります。ここに書いておくと、まだ空のフォルダも候補に出て、説明は Jev の判断材料になります。

Jev による自動仕分け

TypeSafe の Jev に、タイトル・URL・サイト名・説明文・選択テキスト・メモ・候補フォルダを送ります。 保存画面を開いた時点でも自動判定します（キャンセルしても送信済みです）。本文・X の本文は既定では送信しません。 ドメインルールに一致した場合と除外ドメインは送信しません。API 利用料がかかります。

Jev の詳細設定

候補は深さ 3 階層まで、説明のあるフォルダを優先して最大 255 個を送信します。保存画面ではメモを入力後「再判定」を押すと反映されます。

API キーは TypeSafe console で取得できます。
